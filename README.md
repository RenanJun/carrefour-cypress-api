# 🚀 Cypress API Automation - ServeRest

Projeto de automação de testes de API utilizando **Cypress** com JavaScript, validando a API pública ServeRest.

---

## 📌 Objetivo

Garantir cobertura de testes automatizados para a API ServeRest, incluindo:

- Autenticação via JWT
- CRUD completo de usuários
- Testes negativos
- Validações de contrato básicas
- Execução em CI/CD
- Relatórios de execução

---

## 🔗 API utilizada

- Base URL: https://serverest.dev
- Documentação: https://serverest.dev/#/

---

## ⚙️ Tecnologias utilizadas

- Cypress
- JavaScript
- cy.api (@bahmutov/cy-api)
- Node.js
- GitHub Actions (CI)
- Mochawesome (reporting)
